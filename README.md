# TicTacToe
# Two-Player Tic-Tac-Toe

A classic, **two-player Tic-Tac-Toe game** built with a frontend interface using **HTML & CSS** and game logic powered by **Python**. Players take turns locally on the same interface to compete for the win.

Developed by **Aleksandar**.

## Features
* **Two-Player Gameplay:** Play locally with a friend, alternating turns between 'X' and 'O'.
* **Clean Interface:** A responsive and minimalist web grid styled with CSS.
* **Python Power:** Game logic, turn validation, and win-checking handled seamlessly.

## Tech Stack
* **Frontend:** HTML5, CSS3
* **Backend/Logic:** Python

## Getting Started

### Prerequisites
Make sure you have a modern web browser installed (Chrome, Firefox, Edge, or Safari).

### Setup & Launch
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project directory:**
   ```bash
   cd tic-tac-toe
   ```
3. **Launch the Game:**
   Simply double-click the **`index.html`** file (or open it with your preferred web browser) to start playing instantly!

## How to Play
1. The game is played on a 3x3 grid.
2. Player 1 is **X** and Player 2 is **O**.
3. Click on any empty square to place your mark.
4. The first player to get 3 of their marks in a row (horizontally, vertically, or diagonally) wins.
5. If all 9 squares are full and no player has 3 in a row, the game ends in a tie.
